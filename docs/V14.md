# V14：文字 PV 与人物落地

沿用 V13 的音轨、126 组日中歌词、行时间、156 镜剪辑、原角色素材与崩坏窗口。按 `vocaloid-style-mv` 的 JIZURA 手法策划材质、进场、停留、退场和前后文字层，并在现有确定性 Canvas 渲染器内实现。未引入 JIZURA 运行时或重建工程。

| 段落 | 文字与空间动作 | 对照时刻 |
| --- | --- | --- |
| 消去／迫近 | 文字像记录被划去又重新印出；短重复保留完整可读词组，眼部特写留出瞳孔 | 31.35、44.90s |
| 燃旗／沉船 | 字沿街道和倾斜结构展开，破裂时沿不同方向散开 | 47.80、58.30s |
| 黑星／归海 | 字沿黑星的弧线收拢；进入海流时让字和意象一起横向流动 | 63.10、190.60s |
| 窗边记忆／燕迹 | 冷色手书感的轨迹和低透明度背字，给人物和窗光留白 | 195.80s |
| 热异常 | 分版、短促错位和高温色字缘；关键词留在空间中，主阅读字保持完整 | 214.50s |

歌词导演表包含 309 条 cue：126 日文阅读层、126 中文阅读层及 57 背层词段。18 个材质计划包含稳定译文，11 类矢量意象。`tools/build_lyric_direction.py --vocaloid-direction` 只重建导演表，不重建歌词校准或剪辑。

全身人物的鞋底跟随地平面坐标，身体不再随旧的整体入场动画上下漂移；头发、耳朵等局部动作继续。近鞋、远鞋分别有接触阴影，投影方向跟随场景主光。观测站增加椅座、桌脚和前桌沿遮挡；城市人物站上路面，近处护栏分出纵深；窗边记忆使用实坐姿和窗光；核心保留步道承托。近景与有意的局部镜头不强行补出脚。人物环境光仅裁切在角色轮廓内，基础黑白等色彩状态继续生效。

浏览器预览和离线渲染均加载同一 `data/scene_layers.json`，重点镜头可在预览下拉菜单直接跳转。

```powershell
node tools/serve.mjs --port 4173
node tools/check_lyric_layout.mjs --prefix v14-final
node tools/render.mjs --width 1920 --height 1080 --fps 60 --jobs 4 --encoder-threads 2 --chunk-duration 18 --preset fast --crf 18 --output export/LAST-SIGNAL-1080p60-v14.mp4
```

原生 Canvas 的 309 条提示通过入场、读字、退场等五个阶段的边界、字体、显字和寻址检查。浏览器后备渲染验证了 195.8 秒的窗边画面。城市场景检查的 4,964 个鞋底锚点均处于图像相机视野内，坐标是在可选崩坏位移之前测得。行时间校准和画面编排不代表逐字演唱对齐。
