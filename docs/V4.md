# 第四版：镜内动作与转场

针对画面平淡的问题，本轮在既有48镜和31段人物特效上增加连续动作、镜内层次和47次画面转场。角色继续使用图像模型原稿、本地描线重上色与7处局部拆层；没有新增未经生成或描线的角色姿势。全曲第四版已导出并检查，实际媒体结果见QA-V4.md。

## 本轮变化

- 镜头按自身进度推进、拉远、横移和轻微倾斜；眼、手、人物近景使用不同锚点。字幕和HUD在镜头合成后绘制，保持稳定。
- 大字逐字错峰进入并回弹。终端窗口逐段展开、日志输入，数据包沿边缘运行。DELETE/RETRY继续由实际强起音候选切换。
- 人物增加入镜位移、尺度恢复与镜内走位，原有耳、尾、头发、抬手及眨眼继续独立运行。
- 观测站增加分层城市与星体视差、探照灯、玻璃反光和示波器。城市增加逐楼失电、倾倒、落屑、道路流光及电缆摆动。
- 眼部特写加入持续取景移动、瞳内旋转碎片和收紧的遮幅；手部特写加入腕部转动、目标捕获、信号接近、花与碎片释放。
- 黑星吸入碎片并发出起音冲击环。记忆花逐段生长、花瓣脱离；最后传输由聚集点扩展成三条带移动数据包的曲线。

47个切点的实际分配记录在export/v4-motion-plan.json：

| 转场 | 次数 | 画面作用 |
|---|---:|---|
| zoom-echo | 6 | 画面推进与缩放残留 |
| angular-shutter | 8 | 三片错峰斜向遮罩 |
| star-aperture | 6 | 八角星形开口，呼应黑星 |
| digital-slices | 9 | 分条错位替换画面 |
| iris | 8 | 圆形开口进入眼部特写 |
| memory-dissolve | 10 | 记忆、最终信息与关机之间的溶解 |

转场为0.36–0.65秒。记忆段减少运动幅度、使用纸白和粉色；警报以橙色推进，热失控以暗红和红色扩大压力；最后信号恢复薄荷色并逐渐安静。既有人物黑白、网点、负片、散焦与残影叠加在对应角色图层。画面保留少量大字越界与特写裁切；DELETE/RETRY左侧出血属于目前版式。

## 纯时间渲染

src/film.mjs依据歌曲时间、当前镜头起止和音频特征求出文字、人物、花及信号状态。src/cinema.mjs负责空间和眼手特写。src/transitions.mjs先渲染当前画面并施加cameraAt，再由transitionAt选择遮罩或溶解；只有转场期间额外绘制前一镜结束前1/60秒的冻结画面。

合成复用4张离屏画布，每次使用前重置上下文，随后恢复当前人物特效状态。没有累积前一帧，不使用系统时钟或运行时随机数。seek到同一时间可以重新得到同一画面。镜头缩放上限1.1375，倾斜约不超过0.004弧度；开头静音、关机和结尾淡黑限制镜头运动。具体覆盖范围与检查边界以报告为准。

48镜、强起音和BPM依然是音频分析及叙事候选，并未人工校准到人声或小节。添加转场不改变歌曲速度或原时间零点。

## 复现

在工程根目录运行；依赖和素材生成方式见README.md。已有原稿、本地上色图、局部拆层与80张人物特效衍生PNG可直接使用，无需重新调用图像模型。

```powershell
# 预览
node tools/serve.mjs --port 4173

# 原生导出；默认60秒分段，2个工作进程
node tools/render.mjs --jobs 2 --output export/LAST-SIGNAL-1080p60-v4.mp4

# 同一源码的48镜中点与首中尾接触表
node tools/stills.mjs --shots --prefix v4
node tools/check_boundaries.mjs v4

# 完成导出后，检查实际成片
python tools/check_sync.py export/LAST-SIGNAL-1080p60-v4.mp4 --output export/sync-check-v4.json
python tools/check_flash.py export/LAST-SIGNAL-1080p60-v4.mp4 --output export/flash-check-v4.json
node tools/check_chunk_starts.mjs export/LAST-SIGNAL-1080p60-v4.mp4 export/v4-chunk-picture-qa.json

# 全曲完成并确认后，从实际成片提取30秒运动精选
python tools/make_motion_review.py --input export/LAST-SIGNAL-1080p60-v4.mp4 --output export/v4-motion-highlights.mp4

# 可单独重现的转场与高潮短段，静音仅供画面检查
node tools/render.mjs --start 66.7 --duration 6.4 --width 1280 --height 720 --fps 30 --chunk-duration 3.2 --silent --output work/v4-loop-smoke.mp4
node tools/render.mjs --start 166.7 --duration 10.2 --width 1280 --height 720 --fps 30 --chunk-duration 5.1 --silent --output work/v4-climax-smoke.mp4
```

预览地址为http://127.0.0.1:4173/?v=4。预览仍支持逐帧、章节跳转、音频波形、人物特效开关、本地歌词导入与截图。精选工具从最终第四版的12.7、65.7、144.5、166.2、219.2、228.5秒分别截出5秒，重新拼接对应画面与音频，目标为30秒、60fps、1,800帧；生成与验收状态以QA-V4.md为准。

导出器保留独立像素副本、首帧保留断言、编码背压与实际复制接缝检查。最终全曲还需独立解码、音轨偏移及成片画面/同时间直接渲染检查。本地LRC尚缺，头颈、手指和完整身体关节也未独立绑定。
