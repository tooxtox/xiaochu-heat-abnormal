# 第五版：歌词成为场景

记录日期：2026-10-23。

本轮把用户直接提供的126组日中歌词放入画面叙事，取代底部字幕带。按照歌词中的意象重剪63个镜头、34个场景段，复用11种场景表现，并保留既有角色素材、局部拆层、黑白、散焦、负片、网点与残影效果。62处图像转场继续由实际镜头时间控制。

## 文字与动作

| 编排 | 动作与用途 |
|---|---|
| 纵向列 | 分列错开进入，配合变量、眼部与观察记录 |
| 轨道 | 可读下半弧沿黑星排列，半径逐次增加 |
| 道路透视 | 字形随道路斜切，进入城市与坠落的空间 |
| 斜向海报 | 整词冲入或逐字弹入，用于重复、拒绝与临界状态 |
| 分栏 | 两组文字对向进入，构成低语与自我分裂 |
| 曲线 | 字沿贝塞尔弧线从掌心延伸到花与信号 |
| 遮罩显字 | 曲线下划线与局部揭示，用于安静阅读 |

重复句采用完整词组的运动，避免约0.4–0.6秒的短句在字母逐次进入时丢失阅读机会。中文译文拥有独立编排和字体；它不沿用日文词级时间。12处关键词在已进入的歌词内部延后成为低透明度背景回声，人物遮挡它们时仍保留完整的前景阅读层。

阅读层位于图像转场之后，并应用相同的当前镜头变换，因此斜向遮罩、切条或上一镜冻结画面不会切碎当前短句。意象、环境与背景关键词在场景内部合成，保留人物前后景关系。旧的大标题在歌词出现时让出阅读空间，终端面板降低至22%强度。

## 语义对应

`src/lyric_motifs.mjs`提供十类纯时间矢量动画：递归变量网格、电流脉络与烟链、燃烧抽象旗、碎裂折纸船、钟环与落砂、盐晶与泪、鱼群海面、燕迹与灰云、热浪、黑星之眼。每条主阅读记录的`semantic.motif`显式指定意象，未用关键词自动猜测。

黑星重复段使用黑星场景与轨道字；眼睛段进入眼部特写；牵手段进入掌心特写与弧线文字；中枢热异常进入红色核心；现实拒绝段进入破碎城市与受控人物错位。两个较长间奏清空歌词，以花、记忆、观察和信号传输延续叙事。

## 数据与复现

- `data/lyrics_user_supplied.tsv`：用户粘贴的126组正文。
- `data/lyrics.json`：文本、译文与校准行时间，不虚构逐词时间。
- `data/lyric_timing_source.json`：时间来源、126行匹配、六段同版音频偏移比对。
- `data/lyric_direction.json`：126日文阅读层、126中文阅读层、12背景回声，共264条导演记录。
- `tools/build_lyric_direction.py`：从保留的正文和时间证据重建数据，无需联网或工作目录缓存。
- `src/lyric_art.mjs`：字素选择、7种排版与显式未来词隐藏；字宽缓存上限512项。
- `tools/check_lyric_layout.mjs`：实际字形、画面边界、显示区间与反向寻址检查。

字体增加Noto Sans SC及OFL许可，解决部分简体中文字在日文字体中缺字的问题。渲染器及静帧、边界、成片首帧工具统一加载导演数据，允许`--lyrics`和`--lyric-direction`覆盖路径；分段子进程与浏览器后端沿用同一套数据。

行起点来自同一演唱版本的公开LRC，再用实际音频求固定偏移，并抽查所选MV内嵌字幕。图形入字尚不是逐字演唱对齐；三处尾行结束是源字幕清除参考。证据和限制见`V5-TIMING.md`。成片验收另见`QA-V5.md`。
