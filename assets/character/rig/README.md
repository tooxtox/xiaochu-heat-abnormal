# 小初局部二维动画绑定

来源：既有图像模型原稿 → `trace_character.py` 本地自动描边/重新上色 → `build_rig.py` 本地拆层与有限补底。

这些是实际独立的 RGBA 图层：左右猫耳、尾巴、左右外侧长发、抬起的手及袖口、胸前前发。每个全身图层均保持 1024×1536 原画布和原像素坐标。图层图、转轴、最大角度与顺序记录于 `manifest.json`。

绘制时必须按 `drawOrder` 排序，把 `full-base.png` 当作顺序 20 的一层。耳、尾及后发在底图之前，手与前发在底图之后。底图已经移除了这些部分，保留隐藏附件的重叠区；请勿再叠加完整原图。

手/袖口及前发移开后只会露出数像素的局部区域。该区域使用 OpenCV 局部补底，再归入原有 17 色色板。未生成新的人体部位，未声称恢复原稿中不存在的隐藏结构。头颈无法安全分离，因此保持静态并在清单中明确标记不可独立旋转。

`full-blink.png` 及 `calm/fear/sad-blink.png` 是与各自原画布一致的透明眼睑覆盖层。它们只覆盖原眼窝并合成从既有闭眼表情提取、分别对位的睫毛；嘴型和脸保持原表情。`peace` 原图已经闭眼。覆盖层包含局部肤色，不能作为纯黑遮罩使用。

检查材料：`motion-extrema.png`、`qa-ears.png`、`qa-tail.png`、`qa-hand.png`、`qa-hair_front.png`、`qa-hair_back.png` 和 `blink-contact-sheet.png`。已在声明的最大旋转范围检查接缝。静止重组与原图的平均通道差为 0.0075/255，明显差异限于 1,468 个边缘抗锯齿像素。各图层单独旋转的变化像素范围也写入清单，可验证运动确实独立发生。

重建：在项目根目录运行 `python tools/build_rig.py`，依赖沿用 `tools/character-requirements.txt`。
