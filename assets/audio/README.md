# 音源目录

本目录**不含**歌曲音频。

`assets/audio/song.m4a` 的曲目与录音版权属于权利方，因此没有提交到仓库。来源与校验信息保留在 `assets/audio/provenance.json`（只记录公开来源地址、时长与哈希，不含音频本身）。

## 自带音频

把任意你有权使用的音频放成本目录下的 `song.m4a`，或直接在预览页用「替换本地音源」载入。渲染器与预览都按 `config.json` 的 `audio` 字段读取该路径。

注意：歌词排版与镜头切点绑定在**原曲的时间轴**上。换用不同长度的音频时，画面会与声音错位，请自行调整 `data/cues.json` 的场景时间与 `data/shots.json` 的镜头表。

重新分析音频特征：

```bash
npm run analyze
```

歌词文本同样不在仓库内，见仓库根目录 `README.md`。
