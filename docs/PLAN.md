# 小初《熱異常》制作计划

本阶段交付目标是带真实音频的全长画面粗剪，目标规格为 1920×1080、60 FPS、242.538333 秒。媒体导出是否通过，以实际导出文件和 QA 记录为准；项目尚未完成逐句、逐词人声对齐，也尚未完成独立部件角色绑定。

音乐固定为用户选定的 [B 站 BV1eGZLBkE5X](https://www.bilibili.com/video/BV1eGZLBkE5X/)：25時、ナイトコードで。× KAITO《熱異常》2DMV，全曲约 4:03。原始音轨保存在 `assets/audio/song.m4a`，来源和校验值见 `assets/audio/provenance.json`。保持原始零点；开头约 2.729 秒静音，结尾静音约从 241.417 秒开始。

故事采用“最后的观测者”设定：小初在终末观测站记录黑星和城市失效，删除失败后重访记忆，最后将记忆发往未知接收者。界面中的温度、错误码和遥测均为虚构叙事；真实音轨的包络与起音特征只负责部分脉动和波形。

角色按用户要求先由图像模型生成，再用本地 `tools/trace_character.py` 做颜色区域分离、轮廓描摹和固定色板重上色。交付保留原图、线稿、重上色 PNG、描摹 SVG 和四种表情。当前为自动描摹，未宣称人工逐笔描线；当前动作是整张图的条带形变、平移、缩放和轻微旋转，尚非头发、耳朵、尾巴、手臂各自绑定的角色动画。

11 个叙事章节使用非等距候选切点。切点参考真实音频的 RMS、起音及 MFCC/色度变化，再按故事进行编辑分配；它们是粗粒度候选，未经过试听和逐帧人声校准。167 秒附近是本次分析最强音色转折。章节内部采用约 6.2 秒构图变体槽，尚未按乐句或小节校准，具体见 [STORYBOARD.md](STORYBOARD.md)。

色彩依照叙事状态变化：薄荷绿用于在线与观察，橙色用于异常，红色用于临界，深紫用于污染，纸白与粉色用于记忆，近黑用于关机。角色的薄荷发色、耳朵、粉色眼睛、尾巴及薄荷与白色服装保留辨识度。

接下来的验收顺序：检查角色近景和每章代表帧，检查切点附近的构图，完成全曲真实音频粗剪导出，再用最终媒体的尺寸、帧率、帧数、音轨、解码与抽帧结果记录 QA。歌词阶段需要本地全文或 LRC；当前 `data/lyrics.json` 的 `lines` 为空。导入后的插值词时间只能标记为估算，必须试听校准后才能称为逐词同步。

参考项目只提供确定性时间渲染、描摹和导出组织方法，其 BPM、切点、角色与色彩不作为本曲事实。来源说明见 [REFERENCE.md](REFERENCE.md)。
