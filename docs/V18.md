# V18：整片重排与场景重建

把 V17 的 230 镜重排为 177 镜，重新编排全片节奏，并重建五个高权重场景。音轨、126 组日中歌词、行级歌词时间与 JIZURA 阅读层全部沿用 V16 基线，未改音乐、未改歌词文本、未改崩坏时间窗。

## 剪辑依据

`tools/build_v18_edit.mjs` 以选定录音的实测证据驱动剪辑：176 处切点全部来自实测节拍、半拍或瞬态，其中 161 处落在跟踪节拍、13 处落在半拍、154 处同时命中低频强击；6 处实测停顿全部由连续镜头承接，不在停顿里插入切点。帧量化误差最大 6.667 ms。

节奏分三类：

| 节奏 | 用法 | 典型段落 |
| --- | --- | --- |
| `held` | 延长持镜，让画面自己呼吸 | 窗边记忆、档案库、抒情段、终章 |
| `flow` | 按乐句推进，跟随小节网格 | 恐惧/血流、碎声、回归 |
| `accent` | 保留鼓点快切，切点压在重音 | 熔毁、现实崩解与紧接的再现 |

## 场景重建

| 场景 | 实现 | 内容 |
| --- | --- | --- |
| 黑星 | `src/v18_city_3d.mjs`（`star` 配色） | 环形卫星、行星阴影、城市天际线 |
| 废墟 | `src/v18_city_3d.mjs`（`ruin` 配色） | 倾颓楼体、碎块、尘雾 |

`src/v18_room_details.mjs` 为观测走廊、档案库与反应堆补充管线、柜体、检修结构与灯带，使这三个室内空间不再依赖大色块。`src/v17_archive_3d.mjs` 与 `src/v17_reactor_3d.mjs` 在此基础上接入这些细节。

## 渲染与装配

```powershell
node tools/build_v18_edit.mjs
node tools/render.mjs --v18 --gpu --nvenc --output export/LAST-SIGNAL-1080p60-v18.mp4
```

渲染分 11 段（1440 × 10 + 153 帧），母版由 `work/v18/recover-master.mjs` 复制拼接：拼接只复制视频轨，音轨整段复制不重新编码。

## 成片验收

`export/LAST-SIGNAL-1080p60-v18.mp4`：H.264 (h264_nvenc) / 1920×1080 / 60fps / yuv420p，14,553 帧，242.55 秒，824,477,379 字节。

10 个拼接点的解码画面哈希全部匹配，音轨包 SHA-256 与源一致、音轨时间戳未变。逐帧光敏筛查与音画同步检查均通过。验收记录见 `export/LAST-SIGNAL-1080p60-v18.qa.json`、`export/flash-check-v18.json`、`export/sync-check-v18.json`；逐项结论见 `docs/QA-V18.md`。
