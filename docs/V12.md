# V12 · 场景表现力升级

> 《熱異常 / LAST SIGNAL》第十二版。目标不是加特效，而是把「角色立绘 + 简单背景 + 动态文字 + 故障」
> 改成一个**随音乐持续运行、变形、崩坏的世界**。
> 本版不动音乐、歌词文本与时间轴、`data/shots.json` 镜头表、崩坏后期的时间窗设定与角色资产。

## 一、这一版到底改了什么

### 1.1 新增 `src/scene_layers.mjs`：共用场景层工具

一个纯函数、只吃歌曲时间的场景美术工具层。所有随机感来自 `hash(i)` 这类确定性哈希，
不读上一帧、不用 `Math.random()`、不看墙钟，因此同一时刻渲染两次、逆序渲染一遍，结果逐像素一致。

| 工具 | 作用 | 解决的具体问题 |
| --- | --- | --- |
| `citySky()` | 地平线最亮的天空梯度 + 余烬辉光 | 旧版最亮处不在地平线，剪影读不出来 |
| `drawBuilding()` | 退台体块 + 屋顶天线/水箱/楼梯间/招牌 + 窗格 + 轮廓光 + 裂缝 | 楼体从「一个矩形」变成一栋楼 |
| `cityRow()` | 按深度分档滚动的楼群 | 三层之间靠明度差拉开纵深 |
| `streetGround()` / `streetProps()` | 有材质的透视路面 + 路灯 + 车灯 + 人形剪影 | 街道给城市尺度 |
| `depthHaze()` | 空气透视梯度 + 分层雾带 | 层与层之间有可见的雾 |
| `volumeBeam()` | 三层叠加的体积光锥 + 锥内浮尘 | 光不再是一块半透明多边形 |
| `dustMotes()` | 三档速度的悬浮尘埃 | 尘埃有来源、有层级 |
| `rackWall()` / `monitorWall()` | 带背光与边框的机柜阵列 / 屏幕墙 | 每块屏内容不同、刷新相位不同 |
| `truss()` | 上下弦 + 斜腹杆 + 节点板的桁架 | 顶棚有结构 |
| `dataCorridor()` | 透视走廊：肋架 + 角托 + 纵向轨 + 数据包 | 「无限数据空间」有明确透视 |
| `floatingPanel()` | 有厚度、有投影、有背光的悬浮窗口 | 窗口挂在空间里而不是贴在画面上 |
| `brokenClock()` | 七段数码管巨钟，缺段、扫描线、裂纹 | 数据空间的「时间停了」 |
| `redSun()` / `tornClouds()` | 巨大红日 + 撕裂云带 | 末日天空 |
| `floatingRubble()` | 失重下落的建筑碎片与路面板 | 零重力废墟 |
| `warningBar()` / `errorTicker()` / `instrumentTrace()` / `splitPanels()` | 排版化的警告条、错误滚动条、仪器曲线、分屏 | 高密度信息空间有统一视觉语言 |
| `foregroundSweep()` / `nearCable()` | 高速掠过的碎屑与近景线缆 | 前景遮挡层，纵深最便宜的一招 |
| `contactShadow()` / `lightPool()` | 接地阴影与地面光池 | 角色在场景里有落点 |
| `musicState()` | 包络/低频/高频/起音/能量/漂移 | 场景随音乐变化 |
| `composeLayers()` / `composeForeground()` | 按层表组合背景层与前景层 | 环境堆栈由数据驱动 |

### 1.2 新增 `data/scene_layers.json`：层表

11 个场景主题的环境层堆栈全部写成数据：每层的 `kind`、`parallax`（视差系数）、`zone`（back/front）
与 `opts`（颜色、密度、位置）。渲染代码读这张表，不再把层写死在绘制函数里。

- `parallax` 是**场景自身推进速度**的乘数：前景快、远景慢，视差来自速度差而不是素材量。
- `zone:"front"` 的层（前景控制台、近景线缆、碎屑遮挡）在人物**之后**绘制，形成真实遮挡。
- 每层都能被运行时 `overrides` 覆盖，因此音乐能量、段落进度可以实时改变天空色、崩塌度、走廊速度。

### 1.3 重写 `src/cinema.mjs`

- `citySkyline()` 改用 `drawBuilding()`：三层楼群各有退台、屋顶杂件、窗火、轮廓光与裂缝。
- `architecture()` 重写为**观测站外壳**：落地窗（含窗框厚度、竖挺、横档）、两侧墙板与配电箱指示灯、
  有透视接缝与窗光倒影带的地板、顶棚采光缝、近景栏杆。顶部桁架、机柜、光柱、前景台面改由层表提供。
- `ruinedWorld()` 增加：有材质的街道、路灯与车灯光池、人形剪影给尺度、三层尘霾、裂缝与飞散碎片。
- `handInsert()` 的黑色背景补上失重漂浮的建筑碎片。

### 1.6 构图与机位

`src/transitions.mjs` 新增 `FRAME` 表：每个主题一套背景机位（缩放倍率 + 倾斜角 + 锚点）。
- 主题 5 用接近 1 的缩放做**极端广角**，人物在环境里变小。
- 主题 8 的高缩放 + 反向倾斜表现核心塌缩。
- 主题 9 的荷兰角（Dutch angle）表现世界失效。
- 主题 7 保持几乎静止，留出大面积负空间。
- 主题 6 用推进缩放表现坠落。

**背景机位与阅读层机位分离**：`cameraAt(data,t,true)` 是歌词阅读层用的稳定机位，
`cameraAt(data,t)` 是背景机位。新增的倾斜只作用于背景，歌词排版不会被推歪，
因此 `check_lyric_layout` 的越界数保持 0。

## 三、场景如何跟随音乐

全部由 `musicState()` 从既有 `data/audio_features.json` 求值，不引入新的音频分析：

- **鼓点爆发** → 远处建筑出现裂缝（`skyline.ruin = onset`），屏幕出现滚动故障条。
- **音乐能量上升** → 天空逐渐染红（`sky.skyMid` 在两色之间插值），走廊加速（`corridor.speed`）。
- **循环段落** → 走廊窗口数量增加、墙体裂纹随循环次数累积（由 `onset` 计数驱动，确定性）。
- **段落高潮** → 建筑倾斜、崩塌、尘霾加剧（`collapse = progress`）。
- **核心段落** → 熔融核心半径随能量与进度扩张。

## 四、硬约束（全部保持）

1. 纯时间求值的确定性：不读上一帧、不用 `Math.random()`、不看墙钟。
2. 色板语义：只用 `src/palette.mjs` 的语义色，颜色表示系统状态与剧情事件，不是装饰。
3. 崩坏后期仍只在 `src/signal_windows.mjs` 的两个授权窗内（68–90 秒、189–231.69 秒），未改动。
4. 歌词层不回归：`check_lyric_layout` 越界数 0，与 v6–v9 基线一致。
5. 闪光：`check_flash` 通过，worst window 的 opposing transitions 为 1，无 flagged window。
6. 性能：无逐像素操作，无外部贴图，背景层全部为渐变与矢量绘制。
7. 双引擎一致：原生 `@napi-rs/canvas` 与浏览器引擎走同一套 Canvas 2D API。
8. 纯代码绘制：不引入外部纹理与素材，场景可以用 `src/*.mjs` 重新画出来。
9. 1920×1080 / 60 FPS / 纯 Canvas 2D。
