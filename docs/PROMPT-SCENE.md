# 《熱異常 / LAST SIGNAL》场景增强提示词

> 用途：第十一版之后的下一版使用（暂称 V12）。
> 目标只有一个——**把背景与场景从"能看懂的示意图"升级成"有体积、有纵深、有叙事痕迹的世界"**。
> 写法沿用 `docs/BRIEF.md`：给方向、硬约束和验收口径，细节由执行者决定，不要逐条回来确认；做完一段实际抽帧检查，再做下一段。

## 〇、优先级与范围

- **优先级：本文 > `docs/BRIEF.md` 与 `docs/V*.md` 里关于场景的描述 > `docs/KIT.md`。** 与本文冲突的场景相关描述以本文为准。

- **本文不管辖**：小初的角色资产与动作（继续用现有 7 处局部拆层）、歌词排版（保持 v11 基线）、`data/shots.json` 镜头表、音频与切点、崩坏后期的时间窗设定。**这五项本轮一律不动。**

## 一、现在的场景为什么简陋（实测，不是印象）

下面的问题都能在 `export/v11-timeline-review.png` 和代码里当场指出来：

1. **城市是纯色矩形。** `src/cinema.mjs` 的 `citySkyline()` 用 `fillRect` 画楼体，宽度只有两档（`w:[24,58] / [38,84] / [56,114]`），楼顶是一条水平直线，没有天线、水箱、烟囱、招牌、天线塔、窗框凹凸，也没有任何屋顶轮廓变化。
2. **剪影层只有 3 层，且三层之间只有明度差。** 远/中/近的区分靠 `fill` 的深浅，没有雾、没有空气透视、没有遮挡关系，看不出谁在前。
3. **地面是放射线加横线。** `src/film.mjs` 的 `floor()` 只是 `line()` 画的网格，没有材质、没有反光、没有湿感或积尘。
4. **观测站没有体量。** `architecture()` 的室内由 9 根肋线、两块梯形玻璃、几道横线构成，看不出这是一个房间，更看不出是一个观测站。
5. **黑星是一块纯黑圆盘加一圈红环。** `blackStar()` 的内核是径向渐变填出来的黑圆，周围只有环与碎片拖尾，**没有体积、没有引力畸变、没有对周边空间的反作用**——它像贴片，不像一个天体。
6. **抽象空间没有空间。** 场景 2/3 的 `grid()` + `glyphTunnel()` 是覆盖在空底上的线框，窗口没有厚度、没有位置、没有纵深。
7. **场景 7（LAST MEMORY）和场景 8（RUNAWAY）几乎是空的。** 场景 7 是白底 + 一个花 + 一层淡斜纹；场景 8 是一块纯色底 + 一个红圆。**这两段是全片最简陋的地方。**
8. **场景 11（SHUTDOWN）除 HUD 和三行字之外基本没有画面。**
9. **角色没有落点。** 人物多数贴在画面上，没有接地阴影、没有环境反光、没有前景遮挡穿过她，空间关系很弱。

**这一轮的任务就是逐条消除上面 9 项。**

## 二、什么叫"不简陋"（可检查的判定口径）

写完代码后，逐条对照，不满足就返工：

1. **任何一帧至少 5 个可分离的深度层**：天空/远景 / 中景 / 主体 / 前景遮挡。层与层之间必须有可见的遮挡或明度差，不能只是"同一张图上画了几层淡的"。
2. **每层有独立的速度**（视差）：前景最快，远景最慢，静止不动的层不超过 1 层。
3. **剪影边缘不能是直线矩形**：每栋楼/每个结构至少 3 段轮廓变化 + 顶部细节（天线、水箱、楼梯井、招牌、裂缝、窗框凹凸）。
4. **每个场景至少 2 处体积光或大气效果**（光锥、雾层、尘、烟、热浪、雨丝）。
5. **每个场景至少 1 处能读出"这里发生过什么"的叙事道具**（烧过的桌面、倒下的椅子、还在跑的屏幕、散落的档案、烧断的线缆）。
6. **角色必须在场景里有落点证据**：接地阴影 / 地面反光 / 衣角受光 / 被前景雾气或碎片穿过，至少一项。
7. **把文字遮掉，仍然能说出这是哪个场景。** 做不到就说明场景辨识度不够。
8. **画面最暗处仍有可辨形体**，不能糊成一整块纯黑。
9. **对比关系靠"亮天空 / 暗楼体"这类大关系建立**，不靠把楼体调亮。这条是第九版已经验证过的做法，不要推翻。

## 三、全局硬约束（不可违反）

1. **纯时间求值的确定性。** 不读上一帧、不用 `Math.random()`、不看墙钟。随机感一律来自 `hash(i)` 这类确定性哈希。同一时刻渲染两次、逆序渲染一遍，结果必须逐像素一致。
2. **色板语义。** 只用 `src/palette.mjs` 的语义色（mint/teal/orange/red/purple/pink/black/white/paper，由 `config.json` 的 8 个状态驱动）加必要的纯黑纯白。**颜色必须表示系统状态与剧情事件，不是装饰。** 橙色只能在明显升温后出现；大面鲜红仍是全片的重大事件。
3. **崩坏后期仍只在 `src/signal_windows.mjs` 的两个授权窗内**（68–90 秒、189–231.69 秒）。场景增强**不得**让任何损坏类效果溢出窗口，也不得改动这两窗的设定。
4. **歌词层不回归。** 第十一版遗留 19 处相机空间越界（`check_lyric_layout` 实测，源于节奏剪辑的强推移把左边缘歌词字推出画面），本轮**不修它，但也不能新增越界**。
5. **闪光。** 每秒大面亮度反转不超过 3 次；不要用全屏白场做冲击；撕裂图案要保持 ≥6 帧。
6. **性能。** 全曲 60fps 导出耗时不高于现有的十分钟量级。背景层用渐变、离屏缓存画布、复用路径；**不要在逐帧路径里做逐像素操作**。
7. **双引擎一致。** 原生 `@napi-rs/canvas` 与浏览器引擎必须输出逐像素一致；不要用只有浏览器支持或只有原生支持的 API。
8. **纯代码绘制。** 不引入外部纹理贴图，不下载素材。场景必须能用 `src/*.mjs` 重新画出来，保证可复现与体积可控。
9. **1920×1080 / 60 FPS / 纯 Canvas 2D**，与现有导出口径一致。

## 四、先做：共用工具层（所有场景复用）

在 `src/` 新建（或并入）一个场景层模块，提供这些共用件。**每个件都必须是纯函数、只吃歌曲时间。**

| 工具 | 作用 | 要求 |
| --- | --- | --- |
| `depthHaze(c, t, layer)` | 空气透视 | 按层给雾浓度与色偏，越远越接近天空色；层与层之间必须有可见的雾带 |
| `buildingSilhouette(c, t, seed, opts)` | 建筑/结构剪影生成器 | 生成带轮廓变化与顶部细节的轮廓路径，取代现在的 `fillRect` 矩形；同一 `seed` 永远同一形状 |
| `volumeBeam(c, t, origin, angle, opts)` | 体积光锥 | 至少 3 层叠加（核心、边缘、飘尘），不是一条半透明多边形 |
| `groundPlane(c, t, opts)` | 有材质的地面 | 反射（沿用现有竖直镜像思路但要模糊衰减）、接缝、污渍、积水或积尘；反光强度随场景状态走 |
| `dustMotes(c, t, opts)` | 悬浮尘埃 | 只在有光柱/有反差的地方出现；速度分 3 档做视差；不能像噪点 |
| `panelArray(c, t, opts)` | 屏幕/仪表面板阵列 | 每块面板内容不同、刷新相位不同、有边框厚度与反光；不能是同一个矩形复制 |
| `foregroundOccluder(c, t, opts)` | 前景遮挡 | 断线、栏杆、碎块、门框、垂落物，从镜头前掠过；这是拉开空间最便宜的一招 |

**层表**：新建 `data/scene_layers.json`，用数据描述每个场景的层集合、每层的视差速度与雾浓度。渲染代码读这张表，不把层写死在绘制函数里。**同一套层可以在多个场景复用，但每个场景至少有一层是它独有的。**

## 五、逐场景改造

每个场景写四行：**目标画面 / 必须新增的层 / 具体手段 / 代码落点**。

### 场景 1 · INIT（`src/film.mjs` `s.id===1` → `cinema.mjs` `architecture()`）

- **目标**：观众第一眼要认出"一座废弃的巨型观测站的内部"，而不是"一张有窗的黑底图"。
- **新增层**：穹顶桁架与吊灯 / 前景控制台与线缆束（最暗、最快）/ 中景成排机柜 / 窗外远景 / 光柱里的浮尘。
- **手段**：现有 9 根肋线扩成有厚度的桁架（上下两条弦 + 斜腹杆 + 节点）；`panelArray()` 做 3×2 机柜阵列，各屏内容与刷新相位不同；加一条从天花板斜切下来的体积光锥，`dustMotes()` 只在光锥内可见；角色被终端冷光照亮（现有 `seatedTerminal` 的光要扩到人物身上）。
- **落点**：`architecture()` 补桁架/机柜/光柱；`s.id===1` 分支补前景台沿与地面反光。

### 场景 2 · DEAD VARIABLES（`grid()` + `glyphTunnel()`）

- **目标**：把"同一个答案不断返回"变成**空间**：一排排终端形成纵深，尽头是回到原点的同一台机器。
- **新增层**：纵深排列的机柜阵列（透视缩放）/ 有厚度的悬浮窗口（带侧边与投影）/ 地面反射 / 穿过空间的数据瀑布。
- **手段**：`glyphTunnel()` 的方框改成有厚度的矩形柱体（画三条边 + 一条高光边），并按 `fract` 循环让它们迎面掠过；窗口加上"挂在空间里"的重影与遮挡关系；背景机柜阵列提供真实透视。
- **落点**：`glyphTunnel()` 重写；`s.id===2` 分支加机柜阵列与地面。

### 场景 3 · FEAR / TEMPERATURE RISING

- **目标**：温度真的"升起来"了，不只是曲线和数字往上走。
- **新增层**：街道层（不只是天际线）/ 热浪折射 / 城市与观测站之间的玻璃反射 / 天空随温度变色。
- **手段**：`citySkyline()` 之下补一条街道带（路灯光斑、车灯拖影、人形剪影给尺度）；画面局部做水平方向的空气扰动（轻微行位移或波纹采样，纯代码、时间求值）；橙线的起点与城市里的高温点对位。
- **落点**：`s.id===3` 分支。

### 场景 4 · ERASE / PERSIST（DELETE / RETRY 循环）

- **目标**：循环要**磨损**，不是把字重复画一遍。
- **新增层**：同一个机位的房间（走廊/机位）反复出现 / 每次循环多一道裂痕、一块污渍、一盏灭掉的灯 / 最后一次循环房间开始向内收拢。
- **手段**：以 `beat` 计数驱动累积（确定性），循环次数直接决定墙体裂缝数与灯光熄灭数；`DELETE/RETRY` 保留大字，但字号与位置随循环次数漂移。
- **落点**：`s.id===4` 分支（`beat` 已在现有代码里算好，直接用）。

### 场景 5 · BLACK STAR I

- **目标**：黑星要**吞掉空间**，而不只是压在城市上。
- **新增层**：引力透镜（星点被拉成放射线）/ 吸积盘（不是一圈同心圆，是有厚度的、有粒子流、有明暗梯度）/ 被照亮的云层 / 天际线的红来自黑星方向。
- **手段**：`blackStar()` 内的 `rings()` 换成有厚度的吸积盘（椭圆盘 + 内外两圈 + 切向的粒子流 + 靠内侧更亮的梯度）；在黑星周围加一层径向拉伸的星场（复用 `starfield` 的哈希，但沿半径方向拉长）；`citySky()` 的地平线辉光中心对齐黑星位置。
- **落点**：`src/film.mjs` `blackStar()`；`s.id===5` 分支。

### 场景 6 · THE FALL（`ruinedWorld()`）

- **目标**：城市崩塌要有**尺度**，观众要能感到楼很高。
- **新增层**：前景遮挡（断裂楼体/电线/碎块从镜头前掠过）/ 尘暴分层 / 街道尺度参照物（路灯、车辆、人形剪影）/ 垂直方向的坠落节奏。
- **手段**：现有三层楼体已有雏形，重点补前景层与尺度物；楼体轮廓改用 `buildingSilhouette()`；加 2–3 层不同速度的尘带；灯光改为从楼上窗口落下的光柱。
- **落点**：`src/cinema.mjs` `ruinedWorld()`。

### 场景 7 · LAST MEMORY（`s.id===7`）—— **P0，最简陋**

- **目标**：全片最安静的一段，现在白得什么也没有。这一段要做成**一间有阳光的窗边房间**。
- **新增层**：窗与百叶窗（投下斜条纹影）/ 桌面与物件（一只小花、一张摊开的照片、一只杯子）/ 前景窗框或窗帘 / 浮尘在光里 / 浅景深（背景柔化）。
- **手段**：现有米白底保留为"过曝记忆"基调，但必须长出房间：左侧一道窗框与百叶影，右下桌面斜切进来；桌上那朵 `flower()` 已有，让它有影子；光柱里放 `dustMotes()`；角色坐在窗边，接受侧光。
- **落点**：`s.id===7` 分支（纯色底 `fillRect` 处就是改造点）。

### 场景 8 · RUNAWAY / CORE HEAT ABNORMAL（`s.id===8`）—— **P0，最简陋**

- **目标**：现在是"纯色底 + 一个红圆"。要做成**一个正在熔毁的核心空间**：结构向内塌陷、地面开裂、空气被扭曲。
- **新增层**：熔裂地面与热浪 / 四周向内倾倒的结构（观测站骨架被吸向核心）/ 核心内部的裂纹纹理与温度梯度 / 前景飞过的碎片。
- **手段**：核心不能是纯色 `arc()` 填充，改成径向多层梯度 + 内部裂纹纹理 + 外缘不规则的熔融轮廓；背景加同心收缩的结构环（随 `progress` 加速）；地面用 `groundPlane()` 的熔裂变体。
- **落点**：`s.id===8` 分支。

### 场景 9 · REALITY ERROR

- **目标**：世界"失效"要留下证据。
- **新增层**：被翻面的城市剖面 / 镜像与网格化的地面 / 有轨迹的文字碎片（现在是无来源的随机竖线）/ 重力参考（悬浮时要有东西在下落）。
- **手段**：现在的斜线扫掠改成有源头的抛物线轨迹；城市楼体加"翻面"版本（用同一 seed 但做镜像/剖切，让观众看出是同一个世界的错版）；地面网格化。
- **落点**：`s.id===9` 分支。

### 场景 10 · THE LAST MESSAGE（`transmission()`）

- **目标**：信号要有出处，也要去处。
- **新增层**：出发地（她坐着的终端、屏幕余温）/ 途经的真实空间（现在的贝塞尔曲线画在纯黑上）/ 远处的接收端 / 漂浮的记忆碎片。
- **手段**：`transmission()` 目前是黑底上的三条曲线；改成有背景空间的传输路径（从观测站出发、穿过城市上空、指向星空）；曲线上挂碎片而不是纯发光点。
- **落点**：`src/film.mjs` `transmission()`。

### 场景 11 · SHUTDOWN（`s.id===11`）—— **P0，几乎空白**

- **目标**：结尾不能只剩 HUD。观众要看见"她不在了，但系统还在"。
- **新增层**：房间本身（由远及近逐盏熄灭的灯）/ 她站过的地方留下的东西（椅子、终端余温、掉在地上的发带）/ 最终只剩一点薄荷绿的光 / 画面收束成一条记录文件。
- **手段**：现有 `observatory()` + `fillRect` 压黑，改成"逐灯熄灭"的层次序列（由远到近，每盏灯的熄灭都对应一个可听见的音乐事件）；最后 3 秒让整个画面真的收成一条文件行。
- **落点**：`s.id===11` 分支（`ls` 三行字与 `_` 光标处）。

## 六、优先级与工作量

时间有限就按这个顺序做，前三项做完就能明显看出差别：

- **P0（不做就白做）**：场景 7、8、11 三个空场景 → 城市建筑剪影细节（`buildingSilhouette()`）→ 黑星体积。
- **P1**：观测站体量（桁架/机柜/光柱）→ 场景 6 的前景遮挡与尺度物 → 场景 5 的引力透镜。
- **P2**：场景 2/9 的空间化 → 场景 3 的街道层与热浪 → 场景 4 的循环磨损。

**共享工具层（第四节）优先于任何单个场景。** 工具做好了，剩下的场景都是套用。

## 七、验收（必须产出证据，不接受"应该没问题"）

1. **接触表**：11 个场景各取首/中/尾 3 帧，1080p，拼成一张 `export/v12-scene-contact.png`，逐张看过。
2. **判定**：对每张抽帧做"遮字测试"——只看画面，能不能说出是哪个场景；剪影有没有变成纯矩形；纵深能不能读出来；最暗处有没有糊掉。
3. **确定性**：同一组时刻渲染两次 + 逆序渲染一次，逐像素一致（沿用现有导出器的确定性检查）。
4. **歌词不回归**：跑 `node tools/check_lyric_layout.mjs`，越界数量不得超过既有的 19 处。
5. **闪光**：对新增场景段落跑 `python tools/check_flash.py`，最差秒的亮度反转不超过阈值。
6. **双引擎**：浏览器引擎与原生引擎在同一组时刻输出逐像素一致。
7. **性能**：记录全曲导出耗时，与当前值对比。
