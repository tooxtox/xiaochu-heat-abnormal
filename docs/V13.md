# V13 · 城市地面、城市多样性与转场强化

> 《熱異常 / LAST SIGNAL》第十三版。第十二版把场景从"立绘 + 简单背景"升级成分层场景世界，
> 本版针对实测暴露的三个问题继续打磨：**城市没有地面**、**城市单调**、**转场缺少冲击力**。
> 音乐、歌词文本与时间轴、`data/shots.json` 镜头表、崩坏后期时间窗与角色资产仍然不动。

## 一、问题与对应处理

### 1.1 城市没有地面 —— 新增 `cityGround()`

**实测现象**：主题 5 / 9 的城市剪影悬在一片深色空白上，地面只剩一条看不见的深色楔形，
观感是"楼浮在半空"。根因是原来的 `streetGround()` 只画一个从灭点出发的梯形，
颜色接近黑底，且没有路缘、材质、尺度物。

**处理**：新增 `cityGround()`（`src/scene_layers.mjs`），地平面从地平线**铺满整个画面下缘**：

| 元素 | 作用 |
| --- | --- |
| 地平线高光带 | 地面与远景之间的接缝，楼脚不再是断口 |
| 稀疏透视砖缝 + 断续横缝 | 透视，但不做成"坐标纸"（纵向 15 条 → 15 条稀疏、横向改断续） |
| 路缘线 | 明确的地平面边界 |
| 积水（9 处，随天空色反光） | 城市与天空连成一体 |
| 废弃车辆（5 辆，车体 + 车顶 + 轮子 + 车灯光晕） | 尺度参照物 |
| 瓦砾（40 片） | 废墟感 |
| 地面雾带 | 楼脚与地面之间的空气 |

层级顺序也改了：**远景楼群 → 地平面 → 高架桥 → 近景楼群 → 街道道具**，
近景楼体的基线落在地平面之内，楼因此真正"站在地上"。

### 1.2 城市单调 —— 业态化天际线 `cityDistrict()`

原来一排楼是同一个矩形复制。现在每栋楼从 `tower / block / shed / spire` 四种业态里取一种，
各有自己的表面语言：

- **tower 玻璃幕墙**：竖向分格 + 横向楼层带 + 竖排亮窗
- **block 住宅楼**：密集小窗 + 每三层一道阳台线
- **shed 厂房**：波纹板 + 宽门 + 烟囱
- **spire 地标尖塔**：收分塔身 + 桅杆 + 航空障碍灯

另外补了三样让天际线不单调的东西：

- **竖排招牌**：楼体立面上的亮条（远看也能读出来）
- **楼顶招牌**：更亮的横向灯箱，打散楼顶节奏
- **高架桥 `elevatedRoad()`**：横穿画面的桥面 + 桁架 + 桥墩 + 车灯，
  城市因此有了"层"，而不只是楼

观测站窗内的城市视图也换成了同一套业态天际线 + 地面，
所以从室内看出去和外面看到的城市是同一个世界。

### 1.3 去掉旋转转场

`orbit-spin`（画面绕灭点旋转）**已完全移除**，改为更有方向感的 **`whip-pan` 高速甩镜**：
旧画面被横向甩出、新画面从另一侧甩入，附带 18 条横向速度拖影。

### 1.4 新增 5 种转场

| 转场 | 做法 | 触发场景 |
| --- | --- | --- |
| `whip-pan` 高速甩镜 | 横向甩出/甩入 + 速度拖影 | 进出末日都市 |
| `shatter` 世界碎裂 | 旧画面裂成 20 块碎片向外飞开，露出下面已是新世界 | 世界之间的切换 |
| `datamosh` 数字块位移 | 新画面被旧画面的 16 条带切碎错位盖住，再逐条让开 | 场景 4 / 9 的抽象镜 |
| `light-slash` 斜光切开 | 一道斜切的光把旧画面分开，新画面从切口推出 | 常规段落切换 |
| `climax-burst` 高潮爆发 | **放射速度线 + 中心推出 + 扩散光环 + 旧画面碎片 + 色散**（5 层特效） | 前后反差强的地方 |

`glass-crack`（玻璃裂痕）也补上了速度线与光环，升级为全片最重的转场之一。

### 1.5 前后反差强的地方自动升级为强转场

新增 `sceneContrast(data, previousScene, scene)`：

```
反差 = |前后场景色板明度差| + (场景族不同 ? 42 : 0) + (进入英雄主题 ? 18 : 0)
```

判定阈值为 56。命中且不是记忆空间 / 结尾 / 插入镜头时，
转场升级为 `climax-burst`（0.56 秒），**并且优先于节奏快切**——
这一点很关键：高潮段落的第一刀本来是被"疾走快切"吃掉的，
现在它成了全片最重的一击。

实测触发点（节选）：

| 时刻 | 场景变化 | 反差 | 转场 |
| --- | --- | --- | --- |
| 40.30 s | 9 → 6 | 62 | climax-burst |
| 115.50 s | 2 → 3（数据空间 → 实景） | 96 | climax-burst |
| 188.99 s | **进入高潮段** | 104 | climax-burst |
| 199.45 s | 7 → 6 | 73 | climax-burst |
| 212.57 s | 7 → 8（记忆坠入核心） | 153 | climax-burst |
| 215.24 s | 8 → 9（核心 → 断城） | 60 | climax-burst |
| 229.77 s | 9 → 5（断城 → 黑星） | 170 | climax-burst |

**强度分级**：爆发转场的速度线数量、光环强度、碎片数量都按反差值缩放
（`k = clamp((contrast-50)/90, 0.34, 1)`）。反差小的只是"一记闷响"，
反差大的才是"整个世界炸开"，避免 16 次爆发看起来都一样。
