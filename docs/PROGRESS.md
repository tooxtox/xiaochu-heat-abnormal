# 制作进度

## 第十三轮：城市地面、城市多样性与转场强化（当前版本）

记录日期2026-10-23。用户反馈三点：城市高楼场景"没有地面"；城市显得太单调；不要使用旋转转场，
并要求在前后画面对比强的地方（例如进入高潮时）加入更丰富的转场特效。

**城市地面**：新增 `cityGround()`（`src/scene_layers.mjs`）。原 `streetGround()` 只画一条从灭点出发的
深色梯形，贴着暗底几乎看不见，楼体因此像悬在半空。新函数让地平面从地平线铺满整个画面下缘，
并加入地平线高光带、稀疏透视砖缝、断续横缝、路缘、积水倒影（反天空色）、废弃车辆（车体／车顶／轮子／
车灯光晕）、瓦砾与地面雾带。层级也重排为"远景楼群 → 地平面 → 高架桥 → 近景楼群 → 街道道具"，
近景楼体的基线落在地平面之内。

**城市多样性**：新增 `cityDistrict()`，一排楼里混排四种业态——玻璃幕墙塔（竖向分格 + 楼层带 + 竖排亮窗）、
住宅楼（密集小窗 + 阳台线）、厂房（波纹板 + 宽门 + 烟囱）、地标尖塔（收分塔身 + 桅杆 + 航空障碍灯）。
另加竖排招牌、楼顶亮箱与横穿画面的高架桥 `elevatedRoad()`（桥面 + 桁架 + 桥墩 + 车灯）。
观测站窗内景与废墟远景也换成同一套业态天际线，室内外看到的是同一个城市。

**转场**：`orbit-spin`（绕灭点旋转）**已删除**，改为 `whip-pan` 高速甩镜（旧画面横向甩出、新画面从另一侧
甩入 + 18 条速度拖影）。新增 `shatter`（旧画面裂成 20 块碎片向外飞开）、`datamosh`（16 条带切碎错位）、
`light-slash`（斜光切开），以及五层特效的 `climax-burst`（放射速度线 + 中心推出 + 扩散光环 +
旧画面碎片 + 色散）。`glass-crack` 补上速度线与光环，升级为最重的转场之一。

**反差升级**：新增 `sceneContrast()`——`|前后色板明度差| + (场景族不同 ? 42 : 0) + (英雄主题 ? 18 : 0)`，
阈值 56。命中时升级为 `climax-burst`，且**优先于疾走快切**——高潮的第一刀本来是被节奏快切吃掉的，
现在它成了全片最重的一击。爆发强度按反差值缩放（0.34–1.0），避免 16 次爆发看起来一样。
实测触发点包括 115.50 s（数字空间 → 实景）、188.99 s（进入高潮）、212.57 s（记忆坠入核心，���差 153）、
229.77 s（断城 → 黑星，反差 170）。转场共 12 类，全部实测触发。

设计与参数见 `V13.md`，验收证据见 `QA-V13.md`。

## 第十二轮：场景表现力全面升级（历史版本）

记录日期2026-10-23。用户反馈：MV 的场景太简陋，背景缺乏环境细节、空间纵深、视觉叙事与美术表现力；
目标是把「角色立绘 + 简单背景 + 动态文字 + 故障特效」改成一个随音乐持续运行、变形、崩坏的视觉世界。
本轮**不动**音乐、歌词文本与时间轴、`data/shots.json` 镜头表、崩坏后期时间窗与角色资产。

**诊断（实测，不是印象）**：抽帧后发现问题是结构性的，不是"粒子太少"。旧版场景 5/6/9 的城市楼体是
`fillRect` 矩形、剪影只有 3 层且层间只有明度差、地面是放射线加横线、观测站由 9 根肋线构成、
黑星是一块纯黑圆盘加一圈红环、场景 7 是白底加一朵线描花、场景 8 是纯色底加一个红圆、
场景 11 除 HUD 外几乎空白。最关键的一条：**天空的最亮处不在地平线上**，所以剪影读不出来。

**新增共用层** `src/scene_layers.mjs`（纯函数、只吃歌曲时间）：建筑剪影生成器（退台体块 + 屋顶天线/水箱/
楼梯间/招牌 + 窗格 + 轮廓光 + 裂缝）、有材质的透视街道与尺度物（路灯、车灯、人形剪影）、
空气透视、三层体积光、带背光的机柜与屏幕墙、桁架、透视数据走廊、有厚度的悬浮窗口、
七段数码管破损巨钟、红日与撕裂云带、失重碎片、排版化的警告条/错误滚动条/仪器曲线/分屏、
前景碎屑与近景线缆、接地阴影与地面光池，以及 `musicState()`。
新增 `data/scene_layers.json`：11 个场景主题的环境层表（层的种类、视差系数、前景/背景分区与参数），
渲染代码读表而不是把层写死在绘制函数里。

**重写 `src/cinema.mjs`**：`citySky()` 把最亮带移到地平线并加余烬辉光；`citySkyline()` 改用新的建筑生成器；
`architecture()` 重写为观测站外壳（落地窗与窗框厚度、两侧墙板与配电箱指示灯、有透视接缝与窗光倒影带的
地板、顶棚采光缝、近景栏杆）；`ruinedWorld()` 增加有材质的街道、尺度物、三层尘霾与裂缝。

**重写 `src/film.mjs` 的 11 个场景分支**：统一改成「层表堆栈 → 主体 → 前景层」三段式。
数据空间有透视走廊与**小初残影**；记忆场景变成**有阳光的窗边房间**（墙裙、地面、百叶影、窗光斜切、
桌面、相框、杯子、玻璃杯里的小花）；核心场景变成**正在熔毁的核心**（不规则轮廓、炽热边缘、冷却壳板、
向内塌陷的结构环）；结尾变成**逐盏熄灭的吊灯**与她站过的椅子与掉落的发带。

**新增 6 种真正的场景转场**（`src/transitions.mjs`）：`monitor-dive` 冲入显示器、`orbit-spin` 沿建筑高速旋转、
`glass-crack` 通过玻璃裂痕进入废墟、`paper-tear` 强鼓点撕纸、`foreground-wipe` 前景高速掠过遮挡镜头，
加上新增的 `FRAME` 主题机位表（极端广角、荷兰角、推进、静止留白）。

**性能**：全片抽样实测平均 78.5 ms/帧、最差 198.8 ms，单进程投影约 19 分钟。实测确认渐变与小型 fillRect
几乎免费，真正的开销是整帧 `drawImage` 搬运与既有的人物 FX / 崩坏后期通路，因此没有为性能削减场景细节。

设计与参数见 `V12.md`，验收证据见 `QA-V12.md`。

## 第九轮：切点修复、城市重做、黑星染红（历史版本）

记录日期2026-10-24。用户反馈四点：每个镜头最后几帧画面特效没了、恢复了彩色（bug）；城市对比度太低、表现力不足；黑星颜色应为红色与黑色，城市的天空应染成红色并且城市被摧毁；随后追加"还有城市场景依然是原来的风格，都按照新风格"。

**bug 根因**在 `src/glitch.mjs` 的场景进出包络：包络写成 `smooth((span - local) / .4)`，每个镜头最后 0.4 秒被平滑压到 0，崩坏强度整段归零，于是"特效消失、恢复彩色"每场必现。修法有三：包络改为 `(.62 + .38 * sceneEnv)`，**只降到 62%、永不归零**；新增 `sceneLevelAt()` 让场景底噪在切点前后 0.30 秒与相邻场景交叉淡化；新增切点增强 `cutBoost = 1 + .18 * exp(-min(local, span-local) * 7)`，把切点读作"信号在此刻被扯断"。

A/B 用同一套镜头表与阈值做可复现对照：把三处改动回退生成 v8 基线求值器（`work/make_v8_baseline.mjs`），与当前实现并行扫描（`work/compare_v8_v9_glitch.mjs`）。授权窗口内 `glitchAt()` 返回空的帧 **29 帧 → 4 帧**（只剩 68.000 / 90.000 / 189.000 / 231.683 四个窗口边界）；13 个切点的强度最小值中位数 **0.001 → 0.267**，最小值 **0.001 → 0.175**。v8 那 29 个空帧逐条对应 13 个切点各吃掉 1–3 帧，正是"每个镜头最后几帧特效没了"的成因。

注意：`work/v8-glitch-frames.json` 的时间戳晚于本次修复，记录的是修复后的参数，不能当作 v8 基线。

**城市重做**下沉到 `src/cinema.mjs`，新增 `citySky()`（染色天空：地平线最亮、越往上越黑 + `lighter` 地平线辉光）与 `citySkyline()`（三层剪影：远景雾化 / 中景 / 近景近黑，朝画面中心一侧留轮廓光、窗火、崩塌歪斜下沉、红裂缝、地面废墟剪影、上升火星）。观测所窗口、场景 3、5、6（`ruinedWorld`）、9 全部换用同一套。对比度靠"亮天空 / 暗楼体"的剪影关系建立，不靠提高楼体亮度。

**黑星改为红与黑**：`src/film.mjs` 的 `blackStar()` 重写——纯黑吸积内核（内缘烧红）、红色外环、粗黑圈 + 细红环、红黑双色碎片拖尾、灼热红光晕（lighter）、内核红色裂纹。场景 5/8/9 与 `worldShot()` 同步更新。天空同时染红（场景 5 `#7A1920`、场景 6 `#8A271E`、场景 9 `#6B151C`），场景 5/6/9 的城市被摧毁。

顺带修掉浏览器端确定性缺陷：差异集中在人物区域，是缓存画布**内容**在同刻两次渲染间不同。根因三条——缓存键不含尺寸（画布被 `canvas.width` 改写后内容被清空而 key 不变）、`ctx.reset()` 只重置状态**不清空画布**、导出前冷启动。修法：缓存键改为 `${key}@${width}x${height}` 且创建后不再改尺寸、`reset()` 显式 `clearRect`、浏览器导出在确定性检查前做一次热身渲染。复验 `--engine browser` 62.5–65.5s 段 180 帧通过确定性闸门（此前同段必然失败）。原生引擎不受影响。

设计与参数见 V9.md，验收证据见 QA-V9.md。

## 第八轮：颜色让位、人物降级、渲染提速（历史版本）

记录日期2026-10-24。用户反馈三点：RGB 分离没必要一直挂，保留几秒即可，分离时主要显红色；人物可以在几秒里替换成线稿 / 黑白 / 灰度；结合当前机器配置把渲染做快。

RGB 分离从"随底噪常驻"改成"只在 4 级打击上短暂出现"，黑白也从底噪驱动改为打击驱动，噪点与重影的底噪权重下调。分离通道改为红色主导（红通道满权重右移，蓝通道只留 26% 冷边）。实测全片分离总时长 1.43 秒、6 段，其余时间画面保留原色。新增"人物降级"通道：授权窗口内 3 级以上打击按哈希抽签，人物短暂换成线稿 / 单色 / 灰度，实测 4.18 秒、13 次。

性能方面用 `node --cpu-prof` 定位到 72.7% 的时间在像素搬运：放开 `--jobs` 上限（2 → 8，本机 16 逻辑核），人物染色画布降到半分辨率，转场的切片与斜切只搬运可见条带。同一段 30 帧实测 145 → 117 毫秒每帧，全曲导出从约 25 分钟降到约 10 分钟。

顺带修掉一个浏览器端缺陷：崩坏后期多处 `drawImage` 传的是 2D 上下文而非画布元素，原生引擎容忍、浏览器直接抛 TypeError，预览页拖进崩坏窗口就会崩。改传画布元素后对 11 个崩坏时刻整帧哈希比对，11/11 与改前完全一致，第七版成片仍然有效。

设计与参数见 V8.md。

## 第七轮：授权时间窗与信号式歌词排版

记录日期2026-10-24。按用户指示做两件事：崩坏后期只保留在 1:08–1:30 与 3:09 之后两段，其他地方一律不加；歌词当前"风格和动画都太平滑"，与本 MV 风格不符，需要增加卡顿感并重做歌词风格。

新增 `src/signal_windows.mjs` 作为全片唯一的授权表（REPEAT 68–90s / CLIMAX 189–231.69s，各带底噪 floor 与歌词损坏 corrupt）。`glitchAt()` 先查表，窗口外直接返回 null；窗口内强度取 `max(场景底噪, 窗口 floor)`，特效清单、4 级鼓点打击与强度公式全部沿用第六版。以 1/60 秒步长扫描全片，崩坏实际只出现在 68.017–89.983 与 189.067–231.633 两段，其余 218 秒完全干净。

歌词改写为终端解码式排版：入场 8 段、出场 5 段阶梯曲线取代 smoothstep，整块排版锁在 15Hz 信号时钟上；逐字按固定节奏解码进场（跨度 ≤0.62s，且不晚于段落 42%），显式词命中改为 6 级硬切强调；每块歌词外挂四角括号与最多 40 格的解码缓冲读数（全部矢量绘制，不追加文字）；字形从柔和光晕改为硬边套印偏移。授权窗口内再叠色散边、掉字与错位，概率随窗口损坏强度分配，背景意象动画同样阶梯化。

过程中修掉一个既有缺陷：`fract(sin(a*127.1+b*311.7)*43758.5453)` 对连续索引高度相关（相邻字相位每次只推进 0.04 个周期），会出现整串相邻字同时变红。改为整数雪崩混合后桶分布 1923–2091/2000，相邻同类最长连续 3 个。

设计与参数见 V7.md。

## 第六轮：崩坏后期

记录日期2026-10-23。按用户要求在既有画面上增加崩坏后期，重点加在重复段与高潮段，并明确"不必局限于我给的"那几项。

新增 `src/glitch.mjs`：12 类特效，含用户点名的 RGB 分离、颤抖、黑白、黑白色块、描线闪白，另加行位移撕裂、同步滚动条、数据块、局部负片、像素化、噪点雪花与重影。强度按场景分配，重复段 .78、副歌 .46、高潮段 1.00，其余段落保持干净。崩坏由 `data/shots.json` 的 414 个真实鼓点触发，分 4 级打击并带间距约束，因此落在节奏上而不是连续噪声。段落首尾有进出包络。

全过程纯时间求值：不读前一帧、不用随机数、不看系统时钟，同一时刻反复渲染得到同一张图。导出器的确定性检查与首帧保留检查在实渲中通过。

实现中修掉一个渲染器差异：`luminosity` 混合在 @napi-rs/canvas 上会把整帧刷成白色，描线闪白改用已验证的 `color` 混合。RGB 分离最初抽三通道各自错位，强度提上去后绿色重影把画面推成三重彩虹，最终改为只把红通道右移、蓝通道左移再叠加回原帧，原帧保持锐利与白平衡。

HUD 右上角新增 DECONSTRUCT 计量条，预览页新增"崩坏后期"开关，可与"人物特效"对照同一帧。设计与参数见 V6.md。
