不以源码存在代替成片验收。

## 崩坏后期

`src/glitch.mjs` 新增一层纯时间驱动的后期，作用在整幅合成结果上（含阅读层与 HUD）。

- 分区强度：重复段 ERASE / PERSIST .78，副歌 BROKEN VOICE .46，高潮段 CORE 1.00 /
  REALITY .95，其余段落为 0，记忆段与结局完全不崩坏。
- 打击点全部来自 `data/shots.json` 的 414 个真实鼓点，分 4 级并带 0.20 / 0.48 / 0.90 秒
  的间距约束，因此崩坏落在节奏上而不是连续噪声。
- 12 类特效：RGB 分离、颤抖、黑白、黑白色块、描线闪白，以及行位移撕裂、同步滚动条、
  数据块、局部负片、像素化、噪点雪花、重影。
- 段落首尾有 0.6 / 0.4 秒进出包络。

### 渲染器差异

`luminosity` 混合在 @napi-rs/canvas 上会把整帧刷成白色（实测背景由 rgb(9,12,19)
变为 rgb(197,198,200)），描线闪白改用已验证的 `color` 混合。该问题只影响本轮新增的
描线通道，不涉及既有画面。

### 确定性

崩坏全部参数由歌曲时间与鼓点表推出，不读前一帧、不用随机数、不看系统时钟。
导出器的同刻重复渲染哈希比对与首帧保留检查在实际导出中通过。

崩坏效果在重复段与高潮段会主动提高画面变化频率，本次已核对实际成片的筛查窗口数量。
