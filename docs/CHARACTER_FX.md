# 人物特效：第三版

用户补充要求：人物可增加符合整部MV风格的黑白、模糊及其他特效。本轮保持既有角色原稿和局部拆层，在人物合成阶段添加31段特效，集中记录于data/cues.json的characterFx。

| 剧情作用 | 画面处理 |
|---|---|
| 无效变量、警报 | 灰阶，保留清晰面部线条 |
| 删除循环 | 高对比网点印刷、冷色负片、重印残影 |
| 黑色恒星 | 颜色逐渐消失，人物失焦与再聚焦 |
| 城市崩塌 | 黑白主体对照暗红世界，短暂模糊 |
| 最后的记忆 | 少量柔焦，保留薄荷和粉色；掌心花的线条保持清晰 |
| 热失控 | 青红轮廓错位、85毫秒前真实姿态的残影、灰阶印刷主体；细条撕裂限制在脸部下方 |
| 最后信息 | 从低饱和逐渐回到原本颜色，信号保持薄荷色 |

效果仅覆盖人物、手、眼等对应图层，不把整个背景统一模糊。原有耳、尾、发束、手腕与眨眼动画继续运行。人物脸部结构保持，色彩处理是影片中的叙事状态，不会改写原人物PNG。

## 实现与复现

tools/build_character_fx.py生成mono、ink、negative、soft四组非破坏性衍生图，共80张唯一PNG（config.images的重复引用不重复写文件）。灰阶使用实际RGB亮度；网点固定在原图坐标；柔焦在预乘alpha后进行高斯模糊，避免透明边缘发黑。

src/character_fx.mjs在纯时间轴上控制混合、散焦回清、残影、青红轮廓和局部条带。每次合成先重置离屏画布；残影重新求值t−0.085秒的角色动作，不依赖上一帧。人物合成尺寸以实际画面尺寸和源图分辨率为上限，保留脸部可读性并控制开销。

```powershell
python tools/build_character_fx.py
node tools/stills.mjs --shots --prefix v3
node tools/render.mjs --jobs 2 --output export/LAST-SIGNAL-1080p60-v3.mp4
```

jobs默认1；本机16逻辑处理器和16GB内存下用2个工作进程，并仍以60秒视频片段为边界，最后统一合并原音轨。双任务测试检查过帧数和解码接缝。实时多层模糊方案已替换为预计算素材，没有保留为最终导出路径。

导出器以独立像素副本保留每段首帧，并验证后续检查没有改写该副本；成片还会与同一时间的直接渲染进行抽样对照。该检查修复了旧导出器的首帧缓存问题，详情见QA-V3.md。

歌词文件仍待本地LRC，镜头与人声未经过人工逐句校准。人物特效不是完整身体骨骼绑定，也不解决头颈和手指关节尚未拆分的限制。
