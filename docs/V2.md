# 第二版：镜头与角色细节

第二版延续用户选定的 [BV1eGZLBkE5X](https://www.bilibili.com/video/BV1eGZLBkE5X/) 25時、ナイトコードで。× KAITO《熱異常》2DMV 音轨，原始时长 242.538333 秒，保留歌曲零点及 11 章的起点。目标仍为全长 1920×1080、60 FPS 画面粗剪。

本轮主要变化：

- **48 个非等距镜头。** `data/shots.json` 覆盖全曲，无空隙或重叠，镜长 4.05–8.45 秒。36 个章内切点来自真实起音峰；11 个章界与 229 秒传输锁定组成 12 个固定叙事起点。镜头表由 `tools/refine_shots.py` 重建，细节见 [SHOTS.md](SHOTS.md)。约 92.285 BPM 拍网仅作弱候选偏好，未宣称验证了乐句、小节、人声或歌词。
- **景别与空间叙事。** 48 镜包含 9 个环境、4 个全景、6 个手与终端、14 个人物中近景、9 个眼部、6 个抽象图形模式。观测站增加窗、肋架、远城与前景；城市段使用道路、楼体侧面、裂隙和坠落碎片。08、09 章安排脸部与眼部反应，229 秒以后保持传输，不切回角色。
- **7 个实际独立角色图层。** 全身原图拆出左右耳、尾巴、左右外侧后发、抬手及袖口、胸前前发，各有独立透明 PNG、转轴和绘制顺序。底图移除了对应部分，手与前发的小块露出区域经过本地补底及原色板量化。`config.json` 的 `rigs` 已导入绑定清单，并以 `imageKey` 关联已加载的图层资源。
- **局部闭眼覆盖。** 全身以及 calm / fear / sad 有各自对位的眼睑覆盖层，复用已有闭眼原稿的睫毛；嘴与脸保留原表情。peace 原稿已闭眼。此处为局部覆盖与小幅二维变换，头颈仍在静态底图中。
- **新增双眼与手部原稿。** 图像模型生成后，由 `tools/trace_details.py` 在本地复用颜色分离、轮廓描摹和重上色。双眼素材为完整不透明的 1672×941 横幅，保留双粉眼与薄荷刘海；手部为 1536×1024 透明素材，保留五指、象牙蕾丝袖口与薄荷蝴蝶结。原图、线稿、重上色 PNG、SVG 及对比图都在 `assets/character/`，独立方法记录为 `trace-details.json`，提示摘要见 [PROMPTS.md](PROMPTS.md)。
- **循环文字跟随测得起音。** `loopOnsets` 从 1181 个检测峰的强度总体取第 65 分位阈值 0.73098，保留 414 个实际检测时间，供 DELETE / RETRY 的事件计数使用。它们不是固定频率，也不是经过人工确认的人声音节；JSON 中明确记录 `verified: false`。
