# 镜头尾段调色回退修复

日期：2026-10-23。基于当前工程继续修复，保留已完成的城市、黑星、歌词和授权时间窗设计。

根因有两层：`characterFxAt()`在每个效果区间末尾统一淡出0.35秒；散焦、灰阶和残影的混合量又随镜头进度减弱，导致最后1–2秒接近原色。现在基础调色在整个效果区间保持，切镜由既有图像转场衔接。眼部/手部特写和人物主体共用此修复。另修正了`sceneLevelAt()`尾部交叉混合的权重方向，避免提前跳到下一场的强度。

鼓点触发的短促RGB、黑白打击、人物瞬时降级，以及授权窗口出口仍沿用原有时间控制。

验证结果：

- `node tools/check_fx_tail.mjs`：63个效果区间的最后2秒按60Hz采样，共7,530次，检查主体及特写调色在尾段保持；旧实现作为反例会失败。
- `export/fx-tail-regression.json`：上述结果及四组实际画面前后对照。
- `export/fx-tail-before-after.png`：黑白、散焦、残影、灰阶在切镜前一帧的对照，左为修复前、右为修复后。
- `export/fx-tail-glitch-continuity.json`：33个场景边界检查；授权窗口外10,671个60fps时间点均无崩坏效果。
- `export/fx-tail-fixed.mp4`：64.5–67.5秒修复后短片，720p30、90帧、含音频；编码、重复渲染及首帧保留检查通过。

此补丁更新源码、实时预览与后续导出；已有版本成片保留各自原来的画面及验收记录。
